## Decision

Select **rm-853 (operator stream seq-gap surfacing) + rm-854 (SSE multi-line
`data:` join)** as this cycle's single implement batch. Both are ext#38 mints
from this run's assess (83057abb) and research (1a534497) phases, one seam:
the operator-stream parsers and the vendored output reducer.

Why this batch wins the model (impact 50 / risk 25 / effort-inverse 15 /
leverage 10) over the 83-def composed open pool:

- **Impact**: the operator stream is the app's core live surface; a corrupt or
  truncated mid-stream frame currently loses output text with zero
  operator-visible trace (`operator-sse-reader.ts:490-494` logs-and-continues;
  the reducer accepts strictly-increasing seq with no gap check — 'gap' grep = 0
  across all four twin surfaces). This extends the landed degradation-truth arc
  (e49a72a) rather than opening a new front.
- **Risk**: client-only. No protocol change, no contract-version surface, no
  upstream coupling. The standing twin-parity suite guards the four vendored
  surfaces, so regression blast radius is test-bounded.
- **Effort**: M (rm-853: reducer gap flag + view surfacing + red-first tests
  across twins) + S (rm-854: two parser sites + unit tests) — one cycle, fully
  verifiable locally (`pnpm lint`, `pnpm check-types`, targeted vitest,
  parity suite).
- **Lverage**: the surfaced gap signal is the foundation any future stream
  diagnostics hang off; rm-854 closes the spec hole in the same parsers.
- **Collision-freedom** (decisive against the workflow-fix alternatives):
  zero sibling claims on either id (spool/wall/PR scans of 2026-10-10) — no
  integrate-conflict risk, unlike the cve-tripwire zone (see deferrals).
