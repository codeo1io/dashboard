### B1 (lead) — rm-548: Node ≥ 25 kills the web test environment's localStorage

- Surface: `web/src/test-setup.ts` (1 line → guarded shim), NEW
  `web/src/test-env-localstorage.test.ts` tripwire.
- Mechanism, probed first-hand on the sandbox's Node v26.10.0:
  `globalThis.localStorage` is Node's experimental always-`undefined` getter
  (configurable own-property); vitest's jsdom population skips keys Node
  already defines (vitest-dev/vitest#10867), so `window.localStorage` hits
  that getter and throws. The real jsdom Storage is UNREACHABLE (window and
  document.defaultView are the populated global itself — probed), so the
  interim cure is a spec-shaped in-memory Storage installed only when the key
  is actually broken (inert on Node 24 and under vitest ≥ 5).
- Proof: pre-shim `App.test.tsx` 25/25 red at its beforeEach
  `window.localStorage.clear()`; post-shim 27/27 (App + tripwire) green.
  Durable cure stays rm-271's vitest-5/jsdom-30/undici-8 majors window
  (vitest 4.x is a dead end — backport PR #10873 closed unmerged; research
  db73705c0ed1 first-hand); the shim's header names its own deletion window.
- Usage census: web/src uses only getItem/setItem/clear (+ length/key in the
  tripwire); zero sessionStorage consumers → shim stays localStorage-only.

  `appendStreamChunkState` + `drainRecordState`; read loop and drain now use

- Semantics: byte count advances by re-encoding ONLY the unstable suffix — a
  held trailing CR (rm-477's contract, carried inside the helper) plus at most

  surrogate encodes as 3 replacement bytes, a completed pair as 4 — the
  property test FOUND this case and the helper handles it; its byte cost is
  recomputed, never assumed). UTF-8 closure under concatenation makes the
  tail count exactly equal the whole-buffer count. rm-114's 1 MB fail-closed
  cap and every overflow test untouched and green.
- Tests: property against a whole-buffer oracle (fast-check, 400 runs) +
  hostile 7-code-unit drip splitting surrogate pairs and CRLFs mid-token +
  byte-offset drip through the REAL reader (12 cuts) in
  `test/operator-sse-reader.test.ts`; twin-agreement property (300 runs) in
  `test/operator-stream-core.test.ts`. SSE suites 502/502.
- Measured (this run, sandbox Node v26.10.0, 900 KB single record over 4 KB
  chunks): OLD encoder volume across the stream **95,108,502 bytes**; NEW

  1 MB cap. DECLINED at implement, recorded in the def: the chunk-list
