YAML frontmatter (`title`, `category`, `module`, `problem_type`) and is indexed
here; `test/docs-solutions-index.test.ts` guards the mapping in both
directions, so a doc added without an index entry (or a stale link) fails CI.

Adding a doc: create `docs/solutions/<category>/<slug>-<date>.md` with
frontmatter (copy a neighbor's shape), then add its entry to this file under
the matching category heading.
